---
title: Flex
description: A div primitive with display flex and responsive flex utilities.
---

```tsx
import { Flex } from 'mystique-mini-react';
```

`Flex` renders a `div` with `display: flex`. Use the ordinary system utilities
for axis, alignment, wrapping, and sizing.

```tsx
export function Toolbar() {
  return (
    <Flex
      align="center"
      direction={{ base: 'column', md: 'row' }}
      gap="3"
      justify="space-between"
      wrap="wrap"
    >
      {/* toolbar items */}
    </Flex>
  );
}
```

`align`, `justify`, `direction`, `wrap`, `basis`, `grow`, and `shrink` are
styled-system utilities rather than component-only props. This keeps their
responsive and conditional behavior consistent across every primitive.
